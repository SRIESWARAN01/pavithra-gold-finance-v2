# Pavithra Gold Finance (PGF) - Master Requirements Documentation

Welcome to the Master Requirements Document (MRD) repository for **Pavithra Gold Finance (PGF)**. This repository houses the complete, enterprise-grade blueprints, architectures, designs, and workflows for a production-ready Gold Loan / Pawn Broking application.

## Tech Stack Overview

| Layer | Technology |
|---|---|
| **Frontend** | Next.js (Latest), TypeScript, Tailwind CSS, Shadcn UI |
| **Backend** | Node.js, Express.js |
| **Database** | PostgreSQL |
| **Authentication** | JWT (JSON Web Tokens) |
| **Storage** | Cloud Storage (S3 / GCP Bucket equivalent) |
| **Notifications** | Firebase Cloud Messaging (FCM), WhatsApp Business API, SMS Gateway |
